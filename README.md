# סל קל — קטלוג מוצרים

משימה אוטומטית שרצה כל יום, אוספת את קובצי שקיפות המחירים של רשתות השיווק (לפי חוק המזון),
ובונה מהם `catalog.json` — כל המוצרים, ממוינים למחלקות של סל קל. האפליקציה טוענת את הקובץ הזה.

- `collect.py` — האיסוף והסיווג
- `categories.json` — מילון המחלקות של סל קל
- `report.txt` — סיכום ההרצה האחרונה
- הרצה ידנית: Actions → "עדכון קטלוג מוצרים" → Run workflow
